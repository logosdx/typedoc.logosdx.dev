    Class Deck

    Coordinates the single <slides> deck in a document. One deck owns the viewport, the keys, and the URL hash, so only one Deck may be live at a time. Importing this module never creates one.

    Example

    const deck = new Deck();

        deck.on('deck:ready', ({ slide }) => console.log('starting at', slide));

        // later, before building a new deck
        deck.destroy();
